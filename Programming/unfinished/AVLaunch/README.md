# AVL Programming Problem

## Overview
In this challenge, you will insert a series of nodes into an AVL tree. The flag will be derived from the rotations which will take place on nodes to keep the tree balanced after an insertion.


## Instructions
### Reading the Nodes
You have been provided with the file `nodes.txt` which contains the nodes which will be inserted into the AVL tree in the provided order. There is one node per line. Each node contains an positive integer in decimal which should be used as the key by which to sort the node into the tree along with, seperated by a comma, a single ASCII character which will be the node's stored data.

### Printing the Flag
The flag is generated by printing out a node's data field when its insertion into the tree requires more than one rotation to occur in order to keep the AVL tree balanced. These printed ASCII data fields should then be submitted between the normal flag braces: "flag{...DATA...}".
